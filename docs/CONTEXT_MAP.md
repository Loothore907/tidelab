## Implementation areas

- `src/tidelab/domain.py`, `config.py`: canonical market, capability, and configuration contracts.
- `src/tidelab/coinbase.py`, `stream.py`: bounded public reference-adapter ingestion and observations; not an approved strategy-data source.
- `src/tidelab/storage.py`, `service.py`, `cli.py`, `__main__.py`: local persistence, orchestration, and entry points.
- `research/first-pass-universe-v1.json`, `src/tidelab/universe_coverage.py`: fixed five-asset plan and read-only exact-source coverage gate; no ranking or data acquisition.
- `src/tidelab/strategy_intake.py`, `src/tidelab/pine_source.py`, `scripts/strategy_intake.py`, `research/examples/strategy-intake-synthetic-v1.json`: source metadata validation, append-only local intake and ignored exact-byte Pine snapshots. These do not download, execute or implement a strategy.
- `src/tidelab/strategy_batch.py`, `scripts/strategy_batch.py`, `research/examples/strategy-batch-packages/`: source-bound normalized JSON parser and synthetic batch contract check. `src/tidelab/pine_subset.py`, `scripts/pine_subset_batch.py`, `research/examples/pine-subset-v1/`: exact-byte Pine v5 subset compiler and hand specified synthetic traces. General Pine, paper/repository frontends and a historical batch backend remain open under issue #95.
- `src/tidelab/synthetic_batch_ledger.py`, `scripts/synthetic_batch_ledger.py`: append-only synthetic run/input/outcome records shared by both CLIs, with open-run visibility, fixed fixture/cost identities and read-only recovery of a written artifact. It is not the real research trial registry.
- `src/tidelab/package_lean_parity.py`, `scripts/package_lean_parity.py`, `scripts/package_lean/`: supported normalized packages through Python replay and pinned LEAN order/fill/portfolio components; [contract](decisions/TL-003-PACKAGE-LEAN-PARITY.md), [reproducer and limits](evidence/TL-003-PACKAGE-LEAN-PARITY.md). Synthetic harness clocks, not a production feed.
- `tests/`: fixture-based behavioral checks; `.github/workflows/ci.yml`: remote check definition. Passing local tests does not imply exact-head CI passed.
- `docs/evidence/`: dated observations and bakeoff/preflight reports. A branch's unmerged evidence will not appear on `main` until integration.
