# TL-002: private H1 development runner

Date: 2026-09-25. Owner: [issue #48](https://github.com/Loothore907/tidelab/issues/48). This implements only the preregistered **development** partition of H1 v1. It does not open validation or untouched evaluation, establish paper-readiness, or publish market-data-derived output.

The [OKX U.S. historical-data terms](https://www.okx.com/en-us/help/historicaldata-terms-and-conditions) and linked [U.S. Terms of Service](https://www.okx.com/en-us/help/terms-of-service-us) were rechecked on 2026-09-25; the latter lists a 2026-09-16 update. The historical terms still grant a revocable personal-use license that explicitly includes possession, retention and development of one's own trading strategy. The [archive page](https://www.okx.com/en-us/historical-data) still lists candlestick history from July 2023. This is the source for private local historical research, not a timely H1 forward feed; issue [#3](https://github.com/Loothore907/tidelab/issues/3) retains that separate gate. The runner requires a same-day terms review record and keeps all source rows, trial identity, decisions, metrics and logs under ignored `data/`.

`h1_v1_prepare_private_development.py` reads the existing local SQLite store without writing to it. It requires the exact `okx.historical_archive.candlesticks.1m` source and `okx:BTC-USDT` instrument, 28,344 complete consecutive UTC hourly bars from 2023-06-30 16:00 through exclusive 2026-09-23 16:00, valid OHLCV/native provenance, and 61 source ZIP files whose bytes still match the stored SHA-256 values. It hashes all stored hourly rows and each original archive, then writes a private development input with 168 warmup hours, all scored development hours, and the terminal open. The input, provenance manifest, frozen preregistration, cost/accounting source and integrated code revision are bound to an experiment identity. It refuses a dirty or non-main checkout.

The `h1_v1_private_trial` .NET program accepts only that exact development partition. It rechecks the integrated code, configuration, cost, manifest and input hashes, then runs the existing frozen replay twice at each preregistered base and stress cost. It rejects inconsistent replay and reconciles cash, units and fees before writing the private result. The result retains decisions, fills, marks and strategy/cash/25%-hold/full-hold metrics. Its console output contains only completion and a result hash. `record_local_trial.py` must wrap the command so an immutable attempt row exists before execution and every completed, failed or aborted command is accounted for.

Before any real-data run, use the integrated main revision and recheck the official terms on the UTC run date. Example paths below are local and ignored:

```text
python scripts/h1_v1_prepare_private_development.py --database data/okx/research.sqlite3 --archive-dir data/okx --output-dir data/h1_private/development-<unique-id> --terms-reviewed-utc-date YYYY-MM-DD
python scripts/record_local_trial.py --registry data/h1_v1_trials.sqlite3 --identity data/h1_private/development-<unique-id>/identity.json --phase development --attempt-id <unique-attempt-id> --log data/h1_private/development-<unique-id>/attempt.log -- dotnet run --project scripts/lean_fallback/h1_v1_private_trial/H1V1PrivateTrial.csproj -c Release -- data/h1_private/development-<unique-id>/input.json data/h1_private/development-<unique-id>/source-manifest.json data/h1_private/development-<unique-id>/identity.json data/h1_private/development-<unique-id>/result.json
```

Windows may invoke the pinned .NET 10 binary through WSL; the program arguments and working directory must still resolve to the same ignored `data/` bundle. No paid feed, new market-data download, account, order, or public real-data artifact is part of this runner. Its historical full-fill and adverse-price/fee model are declared assumptions, not observed executable liquidity. Validation and untouched evaluation remain separately controlled trial openings after development review; any implementation correction after validation requires a new disclosed trial identity.
