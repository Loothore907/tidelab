# TL-001B: bounded cross-market source screen

Date: 2026-09-24/25. Owner: [issue #3](https://github.com/Loothore907/tidelab/issues/3). This is a read-only source and rights assessment, not a feed selection, strategy result, or order authorization. Data spend remains **$0**.

## Fixed first-pass universe

Freeze five base assets before comparing strategy outcomes: **BTC, ETH, BNB, XRP, SOL**. These are the first five non-stable, non-wrapped assets in the market-cap order displayed by the [OKX U.S. price-history page](https://www.okx.com/en-us/price-history) at this screen. Examine only their **USDT spot** markets, if present in the U.S. historical archive. Do not replace an unavailable pair with a convenient winner. Record it as excluded with the reason. This is a bounded coverage screen, not a claim that any of the five is promising or eligible for the owner's eventual execution venue.

The proposed common screening window is **2023-07-01 00:00 UTC through 2026-09-01 00:00 UTC**, using closed one-hour bars. Require the same source, exact instrument identity, complete hours, source hashes, and logged listing/delisting or missing periods for every included pair. A pair needs at least 24 continuous months inside that common window to enter a comparable broad screen; otherwise retain it as a documented exclusion. Fix screening rules, costs, benchmarks, and a trial budget before ranking any market-strategy combination. The frozen BTC H1 preregistration remains its own one-candidate experiment, not a way to select the other markets after viewing results.

## Disposition

The source supports a **candidate-universe design** and the already validated BTC historical slice. It has **not** cleared the four other pairs' exact historical coverage, nor an accountless timely private research/retention route. Do not rank candidates or start a recorder from this screen. Under #3, the next data action is a bounded terms/coverage resolution for this defined universe, followed only if supportable by exact-pair technical validation. If no no-spend route closes the measured gap, a paid proposal must state source-specific research and post-cancellation retention rights, exact coverage and continuity, the full monthly cap including overage, and a separate owner purchase decision. Issue #48's synthetic H1 accounting and LEAN integration proceeds independently.
