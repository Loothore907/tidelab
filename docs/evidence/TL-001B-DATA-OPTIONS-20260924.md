# TL-001B data options and decision boundary

Read-only source screen, 2026-09-24, for [issue #3](https://github.com/Loothore907/tidelab/issues/3). No provider was contacted in this screen, no data or account was accessed, and no subscription was purchased. Published availability, research rights, depth for an exact instrument, and public presentation rights are separate questions. Prices and terms are point-in-time and must be checked again before a purchase or acquisition.

## What is blocked now

TideLab has plausible deep historical sources. It does **not** yet have one selected source with verified exact-pair coverage, forward continuity, and a supportable basis for local scripted research, retention, and automated analysis. TL-001's Coinbase 30-day probe admitted only 349 of 720 requested hourly bars; [Coinbase terms](https://www.coinbase.com/legal/market_data) create a separate algorithmic-use concern. The Kraken inquiry has only an automated intake response in the bounded 2026-09-24 mailbox check. Neither deficiency blocks synthetic TL-002 paper-authority and LEAN integration, but real-data TL-003 strategy evaluation remains gated. Public real-data-derived charts and results require a separate artifact-specific check.

## Decision and trigger

1. Continue TL-002's synthetic LEAN, policy, ledger and recovery work under [issue #48](https://github.com/Loothore907/tidelab/issues/48). Do not hold that engineering work for a provider reply.
2. Keep TL-001B open. Revisit source selection when Kraken gives a substantive rights answer **or** when the TL-002 synthetic path is ready for a first real-data experiment, whichever comes first. At that point, screen the top zero-cost alternative against the same exact-pair, rights and depth checklist. This avoids repeated broad vendor searches on unchanged evidence.
3. For the first historical test, obtain enough consecutive hourly bars to span distinct market conditions, verify UTC boundaries/gaps/revisions and forward continuity, and use conservative cost/fill assumptions. A bar archive cannot validate bid/ask spread, order queue or intrabar execution. Add quote/trade data only when that precision is needed.
4. If no free source clears the local research gate, return with one explicit capped paid proposal. Include actual price, billing commitment, dataset scope, research/retention rights, source-specific restrictions, and cancellation consequences before spending. Public charts/reports/video remain a separate optional gate.

No source is selected by this screen, and no strategy profitability evidence is created.
