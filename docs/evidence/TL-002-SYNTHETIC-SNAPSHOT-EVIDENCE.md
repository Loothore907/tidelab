# TL-002: synthetic broker snapshot evidence before H1 handoff

Date: 2026-09-25. Owner: [issue #48](https://github.com/Loothore907/tidelab/issues/48). This is a test-owned local broker contract using invented orders, account values and execution IDs. It does not select or access an external broker.

The terminal report alone no longer resolves the H1 paper intent and prepares its next proposal. The handoff requires two matching snapshot reads at the next synthetic opening. Each read declares one consistency token shared by account, orders and executions; identifies the terminal client/broker order and report revision/hash; includes cash and holding that agree with the reconciled execution journal; declares the complete open-order set empty; and marks the order terminal at that cursor. Missing, mixed, stale or contradictory evidence holds the original intent as `submission_unknown` and writes no next intent. The accepted snapshot digest is stored in the same SQLite transaction as the first resolution and next proposal; a replay with different evidence is rejected.

The pinned LEAN mock emitted two identical test snapshots after the invented partial-fill/cancel report. The focused `TL_H1_REPORT_ONLY=1` probe rejected missing and changed reads before permitting the existing next-hour sell proposal; the sell was still submitted only once. Python tests also rejected mismatched account/order/execution revisions, cash, open orders, terminal status, report reference and observation time, and confirmed no next intent after a failed gate. The focused build had 0 errors and 136 existing upstream dependency/toolchain warnings.

The mock constructs its token and report reference from the local fixture. That is only evidence that TideLab's gate behaves as specified; it is not proof of broker atomicity or finality. A future source adapter must demonstrate a source-native consistency token or a repeatable whole-account/order/execution snapshot protocol, including corrections and unknown states. Two matching reads cannot rule out a later correction. Until such evidence exists, the submission barrier remains held. Issue [#3](https://github.com/Loothore907/tidelab/issues/3) independently owns timely forward data and rights. The rejected H1 v1 market hypothesis is not promoted by this synthetic infrastructure test.
